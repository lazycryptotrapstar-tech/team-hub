Publishing setup

Publishing saves your changes straight into the site's repository, and the site rebuilds itself a minute later. To do that it needs a GitHub access token.

  1. Open GitHub's fine-grained token page.
  2. Under Repository access, choose Only select repositories and pick team-hub.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  4. Generate it, copy it, and paste it below.

The token is stored in this browser only, and is only ever sent to GitHub. Anyone who can use this browser can publish with it — keep it off shared machines, and use Forget token when you are done.
